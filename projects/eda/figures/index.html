common.py - constantes, carregamento, limpeza por regra, split e estilo dos gráficos.

Todos os scripts da EDA importam este módulo, então o split e as listas de colunas são
exatamente os mesmos em todas as etapas. Caminhos são relativos a este arquivo, de modo
que tudo roda de um clone limpo do repositório.

from pathlib import Path

import matplotlib as mpl
import matplotlib.pyplot as plt
import numpy as np
import pandas as pd
from matplotlib.colors import LinearSegmentedColormap
from sklearn.model_selection import train_test_split

SEED = 42

ROOT = Path(__file__).resolve().parents[1]           # docs/projects/eda
DATA_FILE = ROOT / "data" / "AB_NYC_2019.csv"
FIGURES = ROOT / "figures"

TARGET = "price"

# Papéis das colunas (definidos na inspeção, etapa 1)
ID_COLS = ["id", "host_id"]                          # identificadores
TEXT_COLS = ["name", "host_name"]                    # texto livre
DATE_COLS = ["last_review"]                          # data (redundante com as contagens de reviews)
DROP_COLS = ID_COLS + TEXT_COLS + DATE_COLS

NUMERIC_FEATURES = [
    "latitude", "longitude", "minimum_nights", "number_of_reviews",
    "reviews_per_month", "calculated_host_listings_count", "availability_365",
]
CATEGORICAL_FEATURES = ["neighbourhood_group", "neighbourhood", "room_type"]
FEATURES = NUMERIC_FEATURES + CATEGORICAL_FEATURES


# --------------------------------------------------------------------- dados
def load_raw():
    """CSV original, sem nenhuma alteração (48.895 linhas x 16 colunas)."""
    return pd.read_csv(DATA_FILE)


def clean(df):
    """
    Limpeza POR REGRA (não aprende nada dos dados, então pode vir antes do split):
    remove anúncios com preço <= 0, que são valores impossíveis para uma diária.
    """
    return df[df[TARGET] > 0].reset_index(drop=True)


def split(df):
    """
    Split 80/20 com semente fixa (random_state=42), estratificado por decis do preço:
    o alvo tem cauda muito pesada e a estratificação garante que treino e teste tenham
    a mesma distribuição de preços (inclusive na cauda). Não há data confiável, então
    um split temporal não se aplica.
    """
    deciles = pd.qcut(df[TARGET], q=10, labels=False, duplicates="drop")
    return train_test_split(df, test_size=0.2, random_state=SEED, stratify=deciles)


def load_split():
    """(train, test) com todas as colunas. A partir daqui, toda estatística vem do treino."""
    train, test = split(clean(load_raw()))
    return train.reset_index(drop=True), test.reset_index(drop=True)

def md_table(df, floatfmt="{:.2f}", index=True):
    """Imprime um DataFrame como tabela Markdown (sem dependências extras)."""
    def fmt(v):
        if isinstance(v, (float, np.floating)):
            return floatfmt.format(v)
        return str(v)
    cols = ([df.index.name or ""] if index else []) + [str(c) for c in df.columns]
    lines = ["| " + " | ".join(cols) + " |", "|" + "|".join(["---"] * len(cols)) + "|"]
    for idx in df.index:
        # df.at preserva o tipo de cada célula (inteiros não viram float, como em iterrows)
        cells = ([str(idx)] if index else []) + [fmt(df.at[idx, c]) for c in df.columns]
        lines.append("| " + " | ".join(cells) + " |")
    return "\n".join(lines)

    A. Dicionário de dados

    Fonte. AB_NYC_2019.csv, o arquivo do conjunto New York City Airbnb Open Data do Kaggle, que descreve anúncios de Airbnb em Nova York com datas de avaliação até 08/07/2019. O arquivo no repositório é uma cópia obtida de um espelho público no GitHub; conferi a forma (48.895 × 16), as contagens de valores ausentes e as estatísticas de price com os valores conhecidos do arquivo original. Não afirmo licença aqui porque não consegui verificá-la; ela está na página do conjunto no Kaggle.

    O que é uma linha. Um anúncio (listing) de hospedagem em Nova York em um instante de 2019. Há 48.895 linhas e nenhum id repetido.

    coluna significado tipo unidade / valores papel

    name título do anúncio texto livre — descartada (texto livre)
    host_id identificador do anfitrião inteiro — descartada (identificador)
    host_name nome do anfitrião texto livre — descartada (texto livre)
    neighbourhood_group distrito (borough) categórica nominal 5 níveis feature
    neighbourhood bairro categórica nominal 221 níveis no arquivo (220 no treino) feature
    latitude latitude do anúncio numérica contínua graus feature
    longitude longitude do anúncio numérica contínua graus feature
    room_type tipo de acomodação categórica nominal 3 níveis feature
    price diária do anúncio numérica inteira dólares por noite alvo
    minimum_nights mínimo de noites por reserva numérica discreta noites feature
    number_of_reviews total de avaliações recebidas numérica discreta contagem feature
    last_review data da última avaliação data (texto) AAAA-MM-DD descartada (ver 1B)
    reviews_per_month avaliações por mês numérica contínua avaliações/mês feature

    availability_365 dias do ano em que o anúncio está disponível para reserva numérica discreta dias (0 a 365) feature

    São 7 features numéricas e 3 categóricas (10 no total), mais o alvo. As colunas descartadas e os motivos estão em 1B.

    B. Qualidade

    As contagens abaixo são regras que não aprendem nada dos dados (contar ausentes, achar valores impossíveis), então foram feitas no arquivo bruto, antes do split (1D). Nenhuma estatística de decisão vem daqui.

    Valores ausentes (as outras 12 colunas não têm nenhum):

    coluna ausentes %
    reviews_per_month 10.052 20,56
    last_review 10.052 20,56
    host_name 21 0,04
    name 16 0,03

    A ausência de reviews_per_month e last_review é estrutural, não aleatória. Os 10.052 anúncios com number_of_reviews == 0 são exatamente os que têm reviews_per_month ausente e exatamente os que têm last_review ausente (interseção de 10.052 nos dois casos, e nenhum anúncio com zero avaliações tem reviews_per_month preenchido). Ou seja, "ausente" aqui significa "ainda sem avaliações", e o valor correto da taxa é 0, não uma média ou mediana.

    Duplicatas: 0 linhas duplicadas (com e sem a coluna id) e 0 ids repetidos.

    Valores impossíveis ou inconsistentes:

    verificação linhas
    price <= 0 11 (preço impossível para uma diária)
    minimum_nights > 365 (mais de um ano) 14 (máximo = 1.250 noites)
    latitude fora de [40,4; 41,0] ou longitude fora de [-74,3; -73,7] 0
    availability_365 fora de [0, 365] 0
    number_of_reviews < 0 0
    availability_365 == 0 (válido, mas atípico) 17.533 (35,9%)

    As 11 linhas com price <= 0 são removidas por regra (um preço de zero não é uma diária). Os 14 minimum_nights acima de 365 são improváveis, mas não impossíveis, e ficam para o tratamento de outliers (4A). Os 17.533 anúncios com availability_365 == 0 são válidos (provavelmente anúncios inativos ou bloqueados), mas não dá para distingui-los dos outros só com este arquivo, então são mantidos.

    Colunas a descartar e vazamento do alvo:

    • id e host_id: identificadores (48.895 e 37.457 valores únicos). Não carregam significado e, como identificadores, um modelo poderia só memorizá-los.
    • name e host_name: texto livre (47.905 e 11.452 valores únicos). Aproveitá-lo exigiria processamento de linguagem natural, fora do escopo desta EDA.
    • last_review: data redundante com number_of_reviews (ausente exatamente quando não há avaliações) e relativa a uma data de coleta que o arquivo não informa. Descartada.
    • Nenhuma coluna é constante.
    • Vazamento do alvo. Investiguei se alguma feature é derivada do preço ou quase uma função dele. Nenhuma tem cara de ser (todas descrevem o anúncio, a localização ou a atividade de avaliações), e a maior correlação de Spearman com price entre as numéricas é |ρ| = 0,440 (longitude), longe de 1. Não há vazamento direto.

    Todas as estatísticas do alvo usam só o treino (o split vem em 1D e foi feito antes desta análise).

    Figura 1. À esquerda, o preço em escala linear (cortado no P99,5 = 1.000 para a massa principal ser visível, com 185 anúncios acima e máximo de 10.000); à direita, em escala log10.

    Conclusão. O preço tem cauda direita muito pesada: a média (152) é 1,44 vez a mediana (106), a assimetria é 18,82 e a curtose 578,5. Há 236 anúncios com preço de 1.000 ou mais e 21 com 5.000 ou mais. Em escala logarítmica a distribuição fica quase simétrica: a assimetria de ln(price) é 0,59 (e a de log1p é 0,61). Por isso o alvo do modelo será ln(price) (4A). Pela cerca de Tukey, 6,0% dos anúncios seriam "outliers" na escala linear (acima de 334), mas apenas 1,28% (499 linhas) na escala log (fora de [17,1; 706,8]).

    D. Treino e teste

    1. Limpeza por regra: removidas as 11 linhas com price <= 0, restando 48.884 anúncios.
    2. Split 80/20 com train_test_split(..., random_state=42), estratificado por decis do preço. Como o alvo tem cauda pesada, a estratificação garante que treino e teste tenham a mesma distribuição de preços, inclusive nos extremos. Um split temporal não se aplica: a única data é last_review, ausente em 20,6% das linhas e sem relação com o preço do anúncio.
    3. Tamanhos: treino 39.107 (80,0%) e teste 9.777 (20,0%).
    preço (USD) treino teste
    média 152,3 154,7
    Q1 69 69
    mediana 106 106
    Q3 175 175
    P90 269 269
    P99 795 800

    O teste de Kolmogorov–Smirnov entre os preços de treino e teste dá estatística 0,0046 (p = 0,996): não há diferença detectável. O treino tem 220 bairros distintos e o teste 200; há 1 bairro que só aparece no teste (Fort Wadsworth, 1 linha), o que será tratado em 4A. A partir daqui, toda estatística aprendida (quantis, médias, desvios, categorias) vem apenas do treino. Nas Etapas 2 e 3, as tabelas e figuras usam só o treino.

    """
Etapa 1 - Inspeção inicial: dicionário (A), qualidade (B), alvo (C) e split (D).

Ordem de EXECUÇÃO: a qualidade (B) usa regras que não aprendem nada dos dados (contagens de
valores ausentes e impossíveis), então roda no arquivo bruto; em seguida a limpeza por regra e o
split (D) acontecem ANTES de qualquer estatística do alvo, e o item C usa só o treino.

import matplotlib.pyplot as plt
import numpy as np
import pandas as pd
from scipy import stats

import common as C

C.apply_style()


def main():
    raw = C.load_raw()

    # ------------------------------------------------------------------ A
    print("=" * 70, "\nA. DICIONÁRIO - tipos, cardinalidade e exemplo\n")
    info = pd.DataFrame({
        "dtype": raw.dtypes.astype(str),
        "n_unicos": raw.nunique(),
        "exemplo": raw.iloc[0].astype(str).str.slice(0, 32),
    })
    info.index.name = "coluna"
    print(C.md_table(info))
    print(f"\nforma bruta: {raw.shape[0]:,} linhas x {raw.shape[1]} colunas")

    # ------------------------------------------------------------------ B
    print("\n" + "=" * 70, "\nB. QUALIDADE (arquivo bruto)\n")
    miss = pd.DataFrame({"ausentes": raw.isna().sum(), "pct": raw.isna().mean() * 100})
    miss = miss[miss.ausentes > 0].sort_values("ausentes", ascending=False)
    miss.index.name = "coluna"
    print("Valores ausentes por coluna:")
    print(C.md_table(miss, floatfmt="{:.2f}"))
    print(f"colunas sem nenhum ausente: {(raw.isna().sum() == 0).sum()} de {raw.shape[1]}")

    print(f"\nlinhas duplicadas (todas as colunas): {raw.duplicated().sum()}")
    print(f"linhas duplicadas ignorando 'id': {raw.drop(columns=['id']).duplicated().sum()}")
    print(f"ids repetidos: {raw['id'].duplicated().sum()}")

    # ausência estrutural: reviews_per_month e last_review só faltam quando não há reviews?
    no_rev = raw.number_of_reviews == 0
    print("\nAusência estrutural de reviews:")
    print(f"  number_of_reviews == 0:                      {no_rev.sum():,}")
    print(f"  reviews_per_month ausente:                   {raw.reviews_per_month.isna().sum():,}")
    print(f"  last_review ausente:                         {raw.last_review.isna().sum():,}")
    print(f"  ausente em reviews_per_month E reviews == 0: {(raw.reviews_per_month.isna() & no_rev).sum():,}")
    print(f"  ausente em last_review E reviews == 0:       {(raw.last_review.isna() & no_rev).sum():,}")
    print(f"  reviews == 0 mas reviews_per_month preenchido: {(no_rev & raw.reviews_per_month.notna()).sum()}")

    print("\nValores impossíveis ou inconsistentes:")
    print(f"  price <= 0:                          {(raw.price <= 0).sum()}")
    print(f"  minimum_nights > 365 (mais de 1 ano): {(raw.minimum_nights > 365).sum()}  (máx = {raw.minimum_nights.max()})")
    print(f"  latitude fora de [40.4, 41.0]:        {((raw.latitude < 40.4) | (raw.latitude > 41.0)).sum()}")
    print(f"  longitude fora de [-74.3, -73.7]:     {((raw.longitude < -74.3) | (raw.longitude > -73.7)).sum()}")
    print(f"  availability_365 fora de [0, 365]:    {((raw.availability_365 < 0) | (raw.availability_365 > 365)).sum()}")
    print(f"  number_of_reviews < 0:                {(raw.number_of_reviews < 0).sum()}")
    print(f"  availability_365 == 0 (válido, mas atípico): {(raw.availability_365 == 0).sum():,} ({(raw.availability_365 == 0).mean()*100:.1f}%)")
    dates = pd.to_datetime(raw.last_review)
    print(f"  last_review: de {dates.min().date()} a {dates.max().date()}")

    print("\nColunas candidatas a descarte:")
    print(f"  constantes: {[c for c in raw.columns if raw[c].nunique() <= 1]}")
    print(f"  id: {raw.id.nunique():,} valores únicos em {len(raw):,} linhas (identificador)")
    print(f"  host_id: {raw.host_id.nunique():,} únicos (identificador)")
    print(f"  name: {raw.name.nunique():,} únicos (texto livre) | host_name: {raw.host_name.nunique():,} únicos")

    # ------------------------------------------------------------------ D (executado antes do C)
    print("\n" + "=" * 70, "\nD. LIMPEZA POR REGRA E SPLIT (seed 42)\n")
    clean = C.clean(raw)
    print(f"linhas removidas por regra (price <= 0): {len(raw) - len(clean)}  -> {len(clean):,} linhas")
    train, test = C.split(clean)
    train, test = train.reset_index(drop=True), test.reset_index(drop=True)
    print(f"treino = {len(train):,} ({len(train)/len(clean)*100:.1f}%) | teste = {len(test):,} ({len(test)/len(clean)*100:.1f}%)")
    qs = [0.25, 0.5, 0.75, 0.9, 0.99]
    comp = pd.DataFrame({
        "treino": [train.price.mean(), *train.price.quantile(qs).values],
        "teste": [test.price.mean(), *test.price.quantile(qs).values],
    }, index=["média", "Q1", "mediana", "Q3", "P90", "P99"])
    comp.index.name = "preço (USD)"
    print(C.md_table(comp, floatfmt="{:.1f}"))
    ks = stats.ks_2samp(train.price, test.price)
    print(f"KS treino vs teste: estatística = {ks.statistic:.4f} (p = {ks.pvalue:.3f})")
    print(f"unicos de 'neighbourhood': treino {train.neighbourhood.nunique()}, teste {test.neighbourhood.nunique()}")

    # ------------------------------------------------------------------ C (só treino)
    print("\n" + "=" * 70, "\nC. ALVO 'price' (somente treino)\n")
    p = train.price
    desc = pd.Series({
        "n": len(p), "média": p.mean(), "desvio": p.std(), "mínimo": p.min(),
        "Q1": p.quantile(.25), "mediana": p.median(), "Q3": p.quantile(.75),
        "P95": p.quantile(.95), "P99": p.quantile(.99), "P99,5": p.quantile(.995), "máximo": p.max(),
    })
    print(desc.round(2).to_string())
    print(f"\nassimetria (skew): {p.skew():.2f} | curtose: {p.kurt():.1f}")

Pearson é sensível à cauda: por exemplo, longitude × preço bruto dá −0,154 por Pearson, −0,328 por Pearson com ln(price) e −0,440 por Spearman, três valores diferentes para a mesma relação.

    """
Etapa 3 - Análise bivariada (somente treino): feature x alvo (3A), feature x feature (3B).
O alvo é analisado em ln(price), a escala em que a relação é mais legível (assimetria 0,59).
"""
import matplotlib.pyplot as plt
import numpy as np
import pandas as pd
from scipy import stats

import common as C

C.apply_style()


def eta_squared(groups):
    """Fração da variância de y explicada pelo grupo (0 a 1)."""
    allv = np.concatenate(groups)
    ss_b = sum(len(g) * (g.mean() - allv.mean()) ** 2 for g in groups)
    return ss_b / ((allv - allv.mean()) ** 2).sum()


def main():
    train, _ = C.load_split()
    train = train.copy()
    train["ln_price"] = np.log(train.price)

        s = train[[c, "ln_price"]].dropna()
        sp = stats.spearmanr(s[c], s.ln_price)
        pe = stats.pearsonr(s[c], s.ln_price)
        rows.append({"feature": c, "Spearman": sp.statistic, "Pearson": pe.statistic, "n": len(s)})
    corr = pd.DataFrame(rows).set_index("feature")
    print(C.md_table(corr.sort_values("Spearman", key=abs, ascending=False), floatfmt="{:.3f}"))
    # Pearson no preço bruto, para mostrar o efeito da cauda

    print({k: round(float(v), 3) for k, v in raw_pe.items()})

    4. Pré-processamento

    O destino dos dados é uma rede neural, que é sensível à escala das entradas, treina com gradiente e não lida com texto nem com NaN. Cada escolha abaixo aponta para o achado que a motivou, e tudo que é "aprendido" vem do treino.

    A. Estratégias

    problema achado que motiva escolha aprendido no treino
    Valores ausentes reviews_per_month ausente em 8.056 linhas de treino, todas com number_of_reviews == 0 (1B); name, host_name e last_review serão descartadas imputar reviews_per_month por 0 (constante). Não é preciso indicador de ausência: number_of_reviews == 0 já o carrega nada (constante)
    Outliers caudas pesadas (Figuras 2 e 3; assimetrias de 3,35 a 21,82); preço com assimetria 18,82 (Figura 1) winsorizar as 4 features de cauda pesada no P99,5 e usar ln(price) como alvo. Nenhuma linha é removida limites do P99,5 por feature
    Codificação 3 categóricas; neighbourhood tem 220 níveis e 112 deles têm menos de 30 anúncios (Figura 5); 1 bairro só aparece no teste (1D) one-hot com min_frequency=30 e handle_unknown="infrequent_if_exist": bairros com menos de 30 anúncios no treino e bairros nunca vistos vão para uma coluna "infrequente" categorias e frequências
    Escala amplitudes de 0,41 (latitude) a 1.249 (minimum_nights); assimetria alta log1p nas 4 features de cauda pesada, depois StandardScaler em todas as 7 numéricas média e desvio

    Detalhes e justificativas.

    • Ordem na coluna de cauda pesada: winsorizar → imputar → log1p → padronizar. O corte é feito antes da imputação para que o P99,5 seja medido só nos valores observados (os 8.056 zeros estruturais imputados depois não devem puxar o quantil para baixo). O P99,5 de reviews_per_month é 8,38, igual ao da Etapa 2.
    • Por que winsorizar e não remover. Os extremos de minimum_nights, number_of_reviews e reviews_per_month são raros (156 a 192 linhas por feature) e podem ser erros ou casos legítimos; o corte mantém a linha e limita seu efeito sobre a escala e sobre a perda quadrática da rede. Os limites são 90, 257 e 8,38 (e 327 em calculated_host_listings_count, que não corta nenhuma linha). Remover linhas também mudaria o conjunto de teste.
    • Alvo em ln(price). A rede é treinada em ln(price) (assimetria 18,82 → 0,59), e as previsões voltam a dólares com exp. Os 499 outliers de preço pela cerca de Tukey em ln (1,28%) são anúncios plausíveis (398 são Entire home/apt) e permanecem; o log reduz a influência deles sem descartá-los. Uma ressalva: exp da previsão em ln estima a mediana condicional, e não a média, então a previsão em dólares tende a ficar abaixo da média.
    • One-hot em vez de embeddings ou target encoding. É simples e não usa o alvo (o target encoding exigiria validação cruzada para não vazar). Embeddings aprendidos são uma alternativa para o projeto de modelagem.
    • Limiar 30. Bairros com menos de 30 anúncios cobrem só 2,8% das linhas (Figura 5), então agrupá-los perde pouco e evita colunas quase vazias. Das 220 categorias, 108 ficam individuais e 1 coluna "infrequente" cobre as 112 restantes (mais qualquer bairro novo).

    """
preprocessing.py - pipeline de pré-processamento da EDA (importável pelo projeto de modelagem).

Tudo o que "aprende" algo dos dados (quantis do winsorizing, médias e desvios do
StandardScaler, categorias do OneHotEncoder) é aprendido em `fit`, que só deve ser chamado
com o TREINO. O teste só passa por `transform`.
"""
import numpy as np
from sklearn.base import BaseEstimator, TransformerMixin
from sklearn.compose import ColumnTransformer
from sklearn.impute import SimpleImputer
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import FunctionTransformer, OneHotEncoder, StandardScaler

import common as C

# Numéricas de cauda pesada: winsorizar -> log1p -> padronizar
HEAVY_TAIL = ["minimum_nights", "number_of_reviews", "reviews_per_month", "calculated_host_listings_count"]
# Numéricas bem comportadas: só padronizar
PLAIN_NUMERIC = ["latitude", "longitude", "availability_365"]
MIN_CATEGORY_COUNT = 30        # categorias com menos de 30 anúncios no treino viram "infrequente"
CLIP_QUANTILE = 0.995


class QuantileClipper(BaseEstimator, TransformerMixin):
    """Winsorizing superior: limita cada coluna ao quantil `q` aprendido no treino (ignora NaN)."""

    def __init__(self, q=CLIP_QUANTILE):
        self.q = q

    def fit(self, X, y=None):
        X = np.asarray(X, dtype=float)
        self.n_features_in_ = X.shape[1]
        self.upper_ = np.nanquantile(X, self.q, axis=0)
        return self

    def transform(self, X):
        return np.minimum(np.asarray(X, dtype=float), self.upper_)

    def get_feature_names_out(self, input_features=None):
        return np.asarray(input_features, dtype=object)


def build_preprocessor():
    heavy = Pipeline([
        # 1) winsorizar ANTES de imputar: o quantil é medido só nos valores observados
        #    (os zeros estruturais imputados depois não devem puxar o P99,5 para baixo)
        ("clip", QuantileClipper(q=CLIP_QUANTILE)),
        # 2) reviews_per_month é NaN exatamente quando number_of_reviews == 0 (ausência estrutural):
        #    "nenhuma review" => taxa 0, então a imputação por constante 0 é o valor correto.
        ("impute", SimpleImputer(strategy="constant", fill_value=0.0)),
        ("log1p", FunctionTransformer(np.log1p, feature_names_out="one-to-one")),
        ("scale", StandardScaler()),
    ])
    return ColumnTransformer(
        transformers=[
            ("heavy", heavy, HEAVY_TAIL),
            ("plain", StandardScaler(), PLAIN_NUMERIC),
            ("cat", OneHotEncoder(min_frequency=MIN_CATEGORY_COUNT, handle_unknown="infrequent_if_exist",
                                  sparse_output=False), C.CATEGORICAL_FEATURES),
        ],
        remainder="drop",              # id, host_id, name, host_name, last_review e price ficam de fora
        verbose_feature_names_out=False,
    )


def build_pipeline():
    """Pipeline completo. O estimador do projeto de modelagem entra como um passo depois de 'prep'."""
    return Pipeline([("prep", build_preprocessor())])


# --------------------------------------------------------------------- alvo
def target_to_model(price):
    """Alvo para o modelo: ln(price) (assimetria 18,8 -> 0,59 no treino)."""
    return np.log(np.asarray(price, dtype=float))


def target_to_price(ln_price):
    """Volta para dólares: exp(ln_price). Métricas de negócio (RMSE/MAE em USD) usam esta escala."""
    return np.exp(np.asarray(ln_price, dtype=float))

def checks(train, test):
    print("=" * 70, "\n4A/4B. PIPELINE AJUSTADO NO TREINO\n")
    pipe = P.build_pipeline().fit(train[C.FEATURES])
    Xtr = pipe.transform(train[C.FEATURES])
    Xte = pipe.transform(test[C.FEATURES])
    names = pipe.get_feature_names_out()
    print(f"treino: {train[C.FEATURES].shape} -> {Xtr.shape} | teste: {test[C.FEATURES].shape} -> {Xte.shape}")
    print(f"NaN após o pipeline: treino {np.isnan(Xtr).sum()}, teste {np.isnan(Xte).sum()}")
    print(f"colunas de saída: {len(names)} = 4 cauda pesada + 3 numéricas + "
          f"{sum(n.startswith('neighbourhood_group_') for n in names)} grupos + "
          f"{sum(n.startswith('neighbourhood_') and not n.startswith('neighbourhood_group_') for n in names)} bairros "
          f"(inclui 'infrequente') + {sum(n.startswith('room_type_') for n in names)} tipos")

    prep = pipe.named_steps["prep"]
    heavy = prep.named_transformers_["heavy"]
    clip = heavy.named_steps["clip"]
    print("\nLimites do winsorizing aprendidos NO TREINO (P99,5):")
    print({c: float(round(u, 2)) for c, u in zip(P.HEAVY_TAIL, clip.upper_)})

    # padronização: treino ~ N(0,1) por construção; teste só aproximadamente (prova de que não houve vazamento)
    num = list(names[:7])
    summ = pd.DataFrame({"treino média": Xtr[:, :7].mean(0), "treino desvio": Xtr[:, :7].std(0),
                         "teste média": Xte[:, :7].mean(0), "teste desvio": Xte[:, :7].std(0)}, index=num)
    summ.index.name = "feature"
    print("\nMédia e desvio das 7 numéricas transformadas:")
    print(C.md_table(summ, floatfmt="{:.3f}"))

    # categorias
    ohe = prep.named_transformers_["cat"]
    nb_idx = C.CATEGORICAL_FEATURES.index("neighbourhood")
    cats = ohe.categories_[nb_idx]
    unseen = set(test.neighbourhood) - set(train.neighbourhood)
    print(f"\nbairros no treino: {len(cats)} | só no teste (nunca vistos): {len(unseen)} "
          f"({test.neighbourhood.isin(unseen).sum()} linhas de teste)")
    inf = ohe.infrequent_categories_[nb_idx]
    print(f"bairros agrupados em 'infrequente' (< {P.MIN_CATEGORY_COUNT} no treino): {len(inf)}")
    inf_col = list(names).index("neighbourhood_infrequent_sklearn")
    print(f"linhas na coluna 'infrequente': treino {int(Xtr[:, inf_col].sum()):,} ({Xtr[:, inf_col].mean()*100:.1f}%), "
          f"teste {int(Xte[:, inf_col].sum()):,} ({Xte[:, inf_col].mean()*100:.1f}%)")
    # sanidade: uma linha com bairro inédito não quebra
    probe = test[C.FEATURES].iloc[:1].copy()
    probe["neighbourhood"] = "Bairro Inexistente"
    pr = pipe.transform(probe)
    print(f"linha com bairro inédito -> transform OK, 'infrequente' = {pr[0, inf_col]:.0f}, NaN = {np.isnan(pr).sum()}")

    # estruturalidade da imputação
    nan_rpm = train.reviews_per_month.isna()
    print(f"\nreviews_per_month ausente: {nan_rpm.sum():,}; destes com number_of_reviews == 0: "
          f"{(train.number_of_reviews[nan_rpm] == 0).sum():,} -> imputação por 0 é exata")

    # alvo
    y = P.target_to_model(train.price)
    print(f"\nalvo ln(price): assimetria {pd.Series(y).skew():.2f} (bruto {train.price.skew():.2f}); "
          f"volta a USD com exp(): máx erro de ida e volta = {np.abs(P.target_to_price(y) - train.price).max():.1e}")
    return pipe, Xtr, Xte, names


def outliers(train, test):
    print("\n" + "=" * 70, "\n4C. OUTLIERS\n")
    # features: linhas atingidas pelo winsorizing
    flagged = pd.DataFrame(index=train.index)
    rows = []
    for c in P.HEAVY_TAIL:
        hi = train[c].quantile(P.CLIP_QUANTILE)
        f = train[c] > hi
        flagged[c] = f
        rows.append({"feature": c, "limite P99,5": hi, "linhas winsorizadas": int(f.sum()),
                     "teste acima do limite": int((test[c] > hi).sum())})
    tab = pd.DataFrame(rows).set_index("feature")
    print(C.md_table(tab, floatfmt="{:.2f}"))
    union = flagged.any(axis=1)
    print(f"linhas com pelo menos uma feature winsorizada (união): {union.sum()} ({union.mean()*100:.2f}%)")
    print(f"  ... e linhas com >= 2 features winsorizadas: {(flagged.sum(axis=1) >= 2).sum()}")

    # alvo: Tukey em ln(price), limites do treino
    lp = np.log(train.price)
    q1, q3 = lp.quantile([.25, .75])
    lo, hi = np.exp(q1 - 1.5 * (q3 - q1)), np.exp(q3 + 1.5 * (q3 - q1))
    t_out = (train.price < lo) | (train.price > hi)
    print(f"\ncerca de Tukey em ln(price) (treino): [{lo:.1f}, {hi:.1f}] USD -> {t_out.sum()} linhas "
          f"({t_out.mean()*100:.2f}%): {(train.price < lo).sum()} abaixo, {(train.price > hi).sum()} acima")
    print(f"  teste fora dos limites do treino: {((test.price < lo) | (test.price > hi)).sum()} linhas")
    print(f"  preço máximo = {train.price.max():,}; >= 1000 USD: {(train.price >= 1000).sum()}; >= 5000: {(train.price >= 5000).sum()}")
    both = t_out & union
    print(f"  interseção (preço outlier E feature winsorizada): {both.sum()}")
    print(f"  composição dos outliers de preço por room_type:")
    print(train.room_type[t_out].value_counts().to_dict())
    print(f"  mediana de minimum_nights: outliers de preço {train.minimum_nights[t_out].median():.0f} vs demais {train.minimum_nights[~t_out].median():.0f}")


def dimred(train, Xtr, names):
    print("\n" + "=" * 70, "\n4D. REDUÇÃO DE DIMENSIONALIDADE (treino)\n")
    pca = PCA(random_state=C.SEED).fit(Xtr)
    evr = pca.explained_variance_ratio_
    cum = np.cumsum(evr)
    print(f"dimensão de entrada: {Xtr.shape[1]}")
    for k in (2, 5, 10, 20, 30, 50):
        print(f"  {k:>2} componentes: {cum[k-1]*100:.1f}% da variância")
    for t in (.80, .90, .95):
        print(f"  componentes para {t*100:.0f}%: {int(np.searchsorted(cum, t) + 1)}")
    print(f"  variância de PC1..PC5: {[round(float(v)*100, 1) for v in evr[:5]]}")

    # cargas: quais colunas dominam PC1-PC3
    load = pd.DataFrame(pca.components_[:3].T, index=names, columns=["PC1", "PC2", "PC3"])
    for pc in load.columns:
        top = load[pc].reindex(load[pc].abs().sort_values(ascending=False).index).head(6)
        print(f"\n  maiores cargas em {pc}:")
        print("   ", {k: round(float(v), 2) for k, v in top.items()})

    # amostra para os métodos não lineares
    rng = np.random.RandomState(C.SEED)
    idx = rng.choice(len(Xtr), 5000, replace=False)
    Xs = Xtr[idx]
    lp = np.log(train.price.values[idx])
    room = train.room_type.to_numpy(dtype=object)[idx]
    Z_pca = pca.transform(Xs)[:, :2]

    results = {}
    for perp in (15, 50):
        t0 = time.time()
        Z = TSNE(n_components=2, perplexity=perp, init="pca", learning_rate="auto", random_state=C.SEED).fit_transform(Xs)
        results[("t-SNE", f"perplexity = {perp}")] = Z
        print(f"\n  t-SNE perplexity {perp}: {time.time()-t0:.0f}s")
    for nn in (15, 50):
        t0 = time.time()
        Z = umap.UMAP(n_neighbors=nn, min_dist=0.1, random_state=C.SEED).fit_transform(Xs)
        results[("UMAP", f"n_neighbors = {nn}")] = Z
        print(f"  UMAP n_neighbors {nn}: {time.time()-t0:.0f}s")

    # métrica objetiva: trustworthiness (k=10) e associação com o alvo (Spearman do alvo vs. média dos 10 vizinhos 2D)
    from sklearn.neighbors import NearestNeighbors
    from scipy import stats

    def nn_target_corr(Z):
        nbr = NearestNeighbors(n_neighbors=11).fit(Z)
        ind = nbr.kneighbors(Z, return_distance=False)[:, 1:]
        return stats.spearmanr(lp, lp[ind].mean(1)).statistic

    grp = train.neighbourhood_group.to_numpy(dtype=object)[idx]

    def nn_agree(Z, labels):
        """Fração dos 10 vizinhos mais próximos (no 2D) que têm o mesmo rótulo do ponto."""
        ind = NearestNeighbors(n_neighbors=11).fit(Z).kneighbors(Z, return_distance=False)[:, 1:]
        return float((labels[ind] == labels[:, None]).mean())

    def row(m, p, Z):
        return {"método": m, "parâmetro": p, "trustworthiness": trustworthiness(Xs, Z, n_neighbors=10),
                "ρ alvo~vizinhos": nn_target_corr(Z), "mesmo room_type": nn_agree(Z, room),
                "mesmo grupo": nn_agree(Z, grp)}

    rows = [row("PCA", "2 componentes", Z_pca)]
    for (m, p), Z in results.items():
        rows.append(row(m, p, Z))
    base_room = float(pd.Series(room).value_counts(normalize=True).pow(2).sum())
    base_grp = float(pd.Series(grp).value_counts(normalize=True).pow(2).sum())
    print(f"\n  acordo esperado ao acaso: room_type {base_room:.3f}, neighbourhood_group {base_grp:.3f}")
    cmp_ = pd.DataFrame(rows)
    cmp_.insert(0, "configuração", [f"{r['método']} ({r['parâmetro']})" for r in rows])
    cmp_ = cmp_.drop(columns=["método", "parâmetro"]).set_index("configuração")
    # referência: mesma métrica no espaço original (124 dim)
    nbr = NearestNeighbors(n_neighbors=11).fit(Xs)
    ind = nbr.kneighbors(Xs, return_distance=False)[:, 1:]
    print(f"\n  referência: ρ(alvo, média do alvo dos 10 vizinhos) no espaço original de 124 dim = {stats.spearmanr(lp, lp[ind].mean(1)).statistic:.3f}")
    print("\n  comparação (5.000 pontos do treino, k = 10):")
    print(C.md_table(cmp_, floatfmt="{:.3f}"))

    # Figura 11: PCA
    fig, axes = plt.subplots(1, 3, figsize=(16, 4.6))
    ax = axes[0]
    n = 30
    ax.bar(np.arange(1, n + 1), evr[:n] * 100, color=C.BLUE, label="Variância de cada componente")
    ax2 = ax.twinx()
    ax2.plot(np.arange(1, n + 1), cum[:n] * 100, color=C.ORANGE, lw=2, label="Variância acumulada")
    ax2.set_ylabel("% acumulada")
    ax2.grid(False)
    ax2.spines["right"].set_visible(True)
    ax2.set_ylim(0, 100)
    ax.set_xlabel("Componente principal")
    ax.set_ylabel("% da variância")
    ax.set_title("Variância explicada (30 primeiros)")
    h1, l1 = ax.get_legend_handles_labels()
    h2, l2 = ax2.get_legend_handles_labels()
    ax.legend(h1 + h2, l1 + l2, loc="center right")
    ax = axes[1]
    sc = ax.scatter(Z_pca[:, 0], Z_pca[:, 1], c=lp, cmap=C.SEQ, s=5, alpha=.8,
                    vmin=np.quantile(lp, .02), vmax=np.quantile(lp, .98))
    fig.colorbar(sc, ax=ax, label="ln(price)")
    ax.set_xlabel(f"PC1 ({evr[0]*100:.1f}%)")
    ax.set_ylabel(f"PC2 ({evr[1]*100:.1f}%)")
    ax.set_title("PC1 x PC2 colorido pelo alvo")
    ax = axes[2]
    for t, col in zip(["Entire home/apt", "Private room", "Shared room"], [C.BLUE, C.ORANGE, C.AQUA]):
        m = room == t
        ax.scatter(Z_pca[m, 0], Z_pca[m, 1], s=5, alpha=.6, color=col, label=t)
    ax.set_xlabel(f"PC1 ({evr[0]*100:.1f}%)")
    ax.set_ylabel(f"PC2 ({evr[1]*100:.1f}%)")
    ax.set_title("PC1 x PC2 por room_type")
    ax.legend(markerscale=3)
    fig.suptitle("Figura 13 - PCA sobre as 124 colunas pré-processadas (treino, 5.000 pontos nos gráficos)", y=1.03)
    fig.tight_layout()
    C.save_fig(fig, "fig13-pca.png")

    for fig_n, method in ((14, "t-SNE"), (15, "UMAP")):
        fig, axes = plt.subplots(2, 2, figsize=(11, 9))
        for j, ((m, p), Z) in enumerate(k for k in results.items() if k[0][0] == method):
            ax = axes[0, j]
            sc = ax.scatter(Z[:, 0], Z[:, 1], c=lp, cmap=C.SEQ, s=5, alpha=.8,
                            vmin=np.quantile(lp, .02), vmax=np.quantile(lp, .98))
            fig.colorbar(sc, ax=ax, label="ln(price)")
            ax.set_title(f"{method}, {p}")
            ax.set_xlabel(f"{method} 1")
            ax.set_ylabel(f"{method} 2")
            ax = axes[1, j]
            for t, col in zip(["Entire home/apt", "Private room", "Shared room"], [C.BLUE, C.ORANGE, C.AQUA]):
                mk = room == t
                ax.scatter(Z[mk, 0], Z[mk, 1], s=5, alpha=.6, color=col, label=t)
            ax.set_title(f"{method}, {p}, por room_type")
            ax.set_xlabel(f"{method} 1")
            ax.set_ylabel(f"{method} 2")
            ax.legend(markerscale=3)
        fig.suptitle(f"Figura {fig_n} - {method} (treino, 5.000 pontos, semente 42)", y=1.01)

    5. Síntese

    Principais achados

    1. O alvo é muito assimétrico, e o log resolve (Figura 1): assimetria de 18,82 para 0,59 em ln(price). O modelo deve prever ln(price).
    2. Localização e tipo de acomodação explicam o preço; as numéricas isoladas explicam pouco (Figuras 8, 9 e 12). room_type explica 38,7% da variância de ln(price), o neighbourhood (108 bairros) 27,7%, o distrito 13,0%, e nenhuma feature numérica passa de |ρ| = 0,44 (longitude); as outras ficam abaixo de 0,14.
    3. O preço tem estrutura radial (Figura 10): decresce com a distância ao centro de Manhattan (ρ = −0,457), por isso latitude e longitude separadas são fracas e a rede precisa combinar as duas (ou receber a distância).
    4. Efeitos aditivos de local e tipo (Figura 11): a ordem dos tipos se mantém em todos os distritos.
    5. Caudas pesadas nas features (Figuras 2 e 3) tratadas com winsorizing em P99,5 + log1p + padronização (479 linhas de treino afetadas).
    6. Ausência estrutural (1B): reviews_per_month é 0 quando não há avaliações, e a imputação por 0 é exata.
    7. Alta cardinalidade em neighbourhood (Figura 5): 112 dos 220 bairros têm menos de 30 anúncios e viram uma coluna "infrequente".
    8. As projeções não lineares mostram que o preço é recuperável a partir da entrada completa (Figuras 14 e 15 e tabela de 4B), ao contrário do PCA (Figura 13).
